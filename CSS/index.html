There are 3 ways to add CSS to HTML

  1. InlineCSS

    Inline CSS is a method of applying styling rules directly to a single HTML element by adding the style attribute inside its opening tag. It allows for immediate, element-specific styling without needing a separate stylesheet or style block

  2. InternaCSS

    Internal CSS (also called embedded CSS) is a method of adding CSS rules directly inside an HTML document using the style tag within the head section. It is used to apply unique, page-specific styling to a single webpage without requiring a separate stylesheet file.

  3. ExternalCSS

    External CSS is a method of styling web pages by writing all CSS rules in a separate .css file and linking it to an HTML document using the tag. This approach separates website design from HTML content, allowing a single stylesheet to control the look of multiple web pages.
